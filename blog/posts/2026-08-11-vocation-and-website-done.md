Vocation 2.0 is done. It took a while to build but Claude definitely made the development process much faster. Making this project was fun and I learned a lot using Claude and ECC.

Ironically enough Claude Code is a skill in itself and there's a community continuously making it better. Even when vibe coding, you still have to make architectural decisions. Knowing the language stack is important too so you can optimize for performance.

There's still so much more to add to Vocation, iterating feels like it can go on forever, but for now I want to stop here and start user testing. I'll be using Google Forms to get consensus from users. Until then, I'm going to experiment on other projects, I have a lot of ideas to try out.
